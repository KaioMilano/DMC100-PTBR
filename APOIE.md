# Apoio voluntário ao DMC100-PTBR

Nossa proposta é publicar ferramentas de pesquisa e documentação sem exigir pagamento. Se o projeto se mostrar útil, apoiadores poderão contribuir, **voluntariamente**, com R$ 5 ou outro valor para cobrir tempo de manutenção, testes de bancada e documentação.

- Não é compra ou pré-venda de firmware.
- Não é requisito para obter o código ou consultar a documentação.
- Não é garantia de resultado, funcionamento ou prazo.
- **Nenhum link de pagamento está ativo no momento.**
- Qualquer arrecadação futura deverá usar canal legítimo definido pelo mantenedor e prestação de contas simples.

Para exibir o botão **Sponsor**, poderemos criar futuramente `.github/FUNDING.yml` com um perfil de arrecadação real e verificado. Não colocaremos PIX ou dados bancários sem decisão explícita do responsável.
