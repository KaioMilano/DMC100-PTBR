# Fontes, referências e limites das evidências

**Fontes externas para consulta; não reproduzir código de terceiros nem binários protegidos sem autorização.**

1. FNIRSI: https://www.fnirsi.com/products/dmc-100
2. Manuais e firmware: https://www.fnirsi.com/pages/manuals-firmwares
3. Distribuidor que lista versões de firmware: https://vx.com.ar/manuales-y-descargas/
4. Engenharia reversa comunitária da V1.4: https://github.com/cakenes/dmc100
5. Experimento com firmware alternativo: https://github.com/ArturBieniek4/DMC100-Doom
6. Relato independente de hardware (confirmar revisão de placa): https://www.mydigit.cn/thread-559140-1-1.html

Os offsets documentados provêm de terceiros e **ainda não foram confirmados contra o binário V1.4 neste repositório**. O projeto DOOM demonstra a execução de outro programa no hardware, **não** um multímetro operacional traduzido.

Um firmware mais recente não significa necessariamente que contenha português. A FNIRSI não participa oficialmente deste projeto.

Consulta de 15/11/2026 e commits das referências de engenharia reversa: [relatório de viabilidade](VIABILIDADE_V14.md). Não foram incorporados pseudocódigo, binários ou imagens dessas fontes.
