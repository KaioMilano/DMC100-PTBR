# Segurança e comunicação de vulnerabilidades

**Este projeto NÃO disponibiliza firmware instalável.** Instrumentos de medição elétrica podem indicar valores incorretos se a interface ou firmware forem modificados inadequadamente.

Não use modificações experimentais em circuitos energizados ou equipamentos em serviço.

Para vulnerabilidades, prefira relato privado via GitHub Security Advisories (se estiver habilitado) ou contato privado previamente combinado com os mantenedores. Não publique instruções perigosas de gravação em issues abertas.

Para erros de tradução ou documentação, use as issues normalmente. Consulte [docs/SEGURANCA.md](docs/SEGURANCA.md).
